# Claude Code Project Guide

This project is a minimal web starter built in plain HTML, CSS, and JavaScript.

## Goals

- Keep the setup lightweight and fast
- Make it easy to iterate on ideas
- Provide a clean foundation for a hackathon or prototype

## Run the app

```bash
python -m http.server 8000
```

Open <http://localhost:8000> in the browser.

## Structure

- `index.html`: single-page application shell
- `README.md`: quick onboarding details

## Working style

- Prefer simple, readable HTML/CSS/JS
- Keep changes focused on the requested feature
- Validate by running the app locally after edits
